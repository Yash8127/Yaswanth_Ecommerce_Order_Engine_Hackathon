## 📖 Project Overview

**E-Commerce Order Engine** is a **console-based Java application** that simulates the core functionality of an online shopping platform.

The project demonstrates strong object-oriented programming principles by managing products, shopping carts, customer orders, payments, and discount coupons using a modular service-oriented architecture.

It is designed as a learning project to strengthen Java fundamentals, clean code practices, and real-world business logic implementation.

---

# ✨ Features

### 🛍 Product Management
- View available products
- Product catalog
- Product information

### 🛒 Shopping Cart
- Add products to cart
- Remove products
- Update product quantity
- View cart items

### 📦 Order Management
- Create customer orders
- Generate order summary
- Calculate total amount
- Order status management

### 💳 Payment Processing
- Simulate payment process
- Validate payments
- Complete order transactions

### 🎁 Coupon System
- Apply discount coupons
- Calculate discounted price
- Coupon validation

### 📝 Logging
- Maintain application logs
- Track important operations
